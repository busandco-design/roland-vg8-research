# Attribution and Prior Work

This project is built on public preservation and reverse-engineering work by many people and communities.

Important public research surfaces include Roland/BOSS service/support documentation, `giulioz/roland-dsps`, The Usual Suspects / Gearmulator, public 39C3/GPN presentations, preservation archives, independent emulator projects, and historical forum/archive contributors.

This seed intentionally does **not** reproduce unpublished correspondence or private collaborator material.

When a contribution relies materially on a particular researcher’s published result, cite that researcher/project explicitly in the same document or source record.
