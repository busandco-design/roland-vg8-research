# Research Workflow

1. Recover provenance first: source, device, version, date, location, hash.
2. Preserve raw evidence; never overwrite originals; publish only what rights allow.
3. Analyze reproducibly with scripts, tool/version notes, and output hashes.
4. Classify results E1–E6 and distinguish direct/comparative/inferred/behavioral claims.
5. Try to falsify; preserve failed hypotheses and contradictions.
6. Integrate through review; side branches are not authoritative by existence.
7. Publish safely: remove proprietary/private material, retain attribution, disclose AI, run the publication checklist/linter.
