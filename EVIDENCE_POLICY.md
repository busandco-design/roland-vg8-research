# Evidence Policy

| Class | Meaning |
|---|---|
| E1 | Byte-verified retained artifact |
| E2 | Primary manufacturer/product evidence |
| E3 | Reproducible software/computational evidence |
| E4 | Comparative same-chip / CSP-family / descendant evidence |
| E5 | Engineering inference or candidate plan |
| E6 | Genuine physical CSP-2 observation |

A semantic claim should state source identity/provenance, device/version scope, evidence class, reproduction method, alternatives, negative results, and a falsifier where practical.

E4 does not become VG-native fact because a related chip behaves similarly. E5 does not become fact because it is elegant. E3 uniqueness does not become silicon truth without a physical basis for the unresolved silicon claim.

Behavioral clone-equivalence and literal silicon-equivalence are distinct claims.

Current top boundaries: CSP-2 late-publication/visibility semantics remain physically unverified; IC22 internal reduction/routing remains open; `TMP320P16PGL` literal internal ROM remains unrecovered; the IC23 behavioral controller model is a behavioral substitute, not recovered ROM code.
