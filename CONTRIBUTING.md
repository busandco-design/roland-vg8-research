# Contributing

For technical claims, include device/version, source type, provenance/URL, hashes when bytes are involved, exact method, result, evidence class, limitations, reproduction steps, and a falsifier/counterexample where practical.

For physical measurements, record device/board/revision, firmware/system version, probe/channel map, test state, clock/sample settings, equipment, run order, and raw-file hashes.

Do not open a pull request containing proprietary Roland/BOSS ROMs, firmware images, service-manual scans, or other copyrighted source artifacts unless redistribution is clearly authorized. Prefer acquisition instructions, original-source links, hashes, extraction scripts, patch offsets against user-supplied files, and derived analysis.

AI-assisted contributions are welcome when disclosed and reproducible. Retractions, failed hypotheses, contradictory measurements, and negative search results are valuable contributions.
