# AI-Assisted Research Disclosure

AI systems have been used as research assistants for source triage, static-analysis assistance, script drafting/review, hypothesis generation, test-plan design, evidence-ledger maintenance, writing, and reconciliation.

An AI-generated statement, model, decompilation, guessed register meaning, or synthesized implementation is not independently authoritative.

Technical results should be admitted only when grounded in byte-verified artifacts, primary sources, reproducible software results, clearly labeled comparative evidence, clearly labeled engineering inference, or qualifying physical observations.

Where AI helps produce code or analysis, preserve source identities, scripts, output hashes, tests/falsifiers where feasible, and assumptions.
