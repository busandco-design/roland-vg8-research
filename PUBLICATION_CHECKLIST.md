# Pre-Publication Checklist

- [ ] No proprietary ROM/firmware bytes without clear redistribution rights.
- [ ] No copyrighted service-manual scans.
- [ ] No private correspondence/unpublished collaborator material without permission.
- [ ] Third-party code retains licenses/notices.
- [ ] External claims have provenance entries.
- [ ] Evidence class is stated.
- [ ] AI-assisted work is disclosed where material.
- [ ] Behavioral substitutes are not described as recovered silicon/ROM.
- [ ] Negative results and known contradictions are retained.
- [ ] Raw physical evidence is hashed/preserved where lawful.
- [ ] `python tools/publication_lint.py .` passes.
- [ ] `python tools/verify_manifest.py .` passes.
- [ ] Final repository license decision has been made before inviting code contributions under specific license terms.
